1. Problem Statement
Large Language Models (LLMs) can assist in analyzing financial statements, but the
quality of their responses depends heavily on how they are prompted. There is
limited practical guidance on which prompting strategies produce the most
accurate, complete, and reliable financial analyses. This project aims to evaluate
different prompting techniques to identify the most effective approach for financial
statement analysis.
Relevance
Prompt engineering is a fundamental aspect of LLM engineering because the quality
of an LLM's output is directly influenced by the prompt design. In financial
applications, inaccurate or incomplete responses can lead to incorrect interpretations
of financial information. Evaluating different prompting strategies helps improve the
reliability and consistency of LLM-based financial analysis while providing practical
insights for real-world business applications.

Risks & Fallback
Technical Risk: Financial statements often contain complex tables and PDF layouts
that may result in incorrect text extraction, affecting the quality of the LLM's
analysis.
Fallback Plan: If PDF extraction proves unreliable, the project will use clean text or
CSV versions of the same financial statements. The evaluation of prompting
strategies will remain unchanged, allowing the core objectives of the project to be
completed successfully.
2. Proposed Approach

The proposed system will accept financial statements (Balance Sheet and Income
Statement) in PDF format, extract the relevant text and financial information, and
analyze them using a Large Language Model (LLM). Our system will evaluate 4
different prompting strategies for financial statement analysis using the Large
Language Model (LLM).
The strategies include
1. Basic Prompting, where the model is asked to analyze the financial statement
directly.
2. Role-Based Prompting, where the model is instructed to act as an experienced
CPA/CA or financial analyst.
3. Structured Prompting, where the model is guided to produce a predefined
analysis covering key financial metrics such as revenue, expenses, profitability,
financial ratios, and potential risks.
4. Few-Shot Prompting, where the model is first provided with an example financial
statement analysis before analyzing a new financial statement. The outputs from
each prompting strategy will be compared using evaluation metrics such as
accuracy, completeness, hallucination rate, and response time to determine the
most effective prompting technique for financial statement analysis.

What is Novel?
Most existing financial document applications use a single prompting approach
without evaluating its effectiveness. This project systematically compares multiple
prompting strategies on the same financial statements using quantitative evaluation
metrics such as accuracy, completeness, hallucination rate, and response time to
identify the most effective prompt design.
Compute Budget
The development will be performed on a standard laptop (8–16 GB RAM) using
Python and Streamlit. LLM inference will be provided through the Gemini API,
eliminating the need for dedicated GPU hardware. Google Colab (Free Tier) may be
used for experimentation and evaluation if needed.
3. Related Work
The proposed project builds upon existing research in financial language models,

prompt engineering, and LLM-based document understanding. Previous studies
have focused on developing domain-specific financial LLMs or improving financial
question answering. However, limited work has systematically evaluated how
different prompting strategies influence the quality of financial statement analysis
using general-purpose LLMs. This project addresses that gap by comparing multiple
prompting techniques and measuring their effectiveness using objective evaluation
metrics.
Reference (Title, Authors, Year)
I. BloombergGPT: A Large Language Model for Finance – Wu et al., 2023
BloombergGPT introduces a finance-specific LLM trained on financial data. In
contrast, this project evaluates how prompt engineering can improve financial
statement analysis using a general-purpose LLM without additional model training.
II. FinGPT: Open-Source Financial Large Language Models – Yang et al., 2023
FinGPT focuses on developing and fine-tuning open-source financial language
models. This project instead compares multiple prompting strategies to improve
analysis quality while using an existing LLM through an API.
III. Prompt Engineering Guide – Lee Boonstra, Google, 2024
The Prompt Engineering Guide describes various prompting techniques for LLMs.
This project applies and experimentally evaluates those techniques in the financial
statement analysis domain using quantitative performance metrics.
